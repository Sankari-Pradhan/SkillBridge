# SkillBridge – Personal Career and Learning Assistant

**Build Your Career. Improve Your Skills. Achieve Your Goals.**

SkillBridge is a career development and learning platform designed to help students and job seekers build their professional skills, explore career opportunities, and prepare for their future careers.

## 🚀 Live Demo

[Visit SkillBridge](https://skillbridge-dka3.onrender.com)

## 🏠 Platform Overview

SkillBridge provides an integrated platform with five main sections.

## ✨ Key Features

### 🏠 1. Home
- Main dashboard of the application.
- Overview of the platform.
- Easy navigation to different sections.

### 📚 2. Learning Hub
- Access learning resources.
- Explore educational content.
- Improve technical and professional skills.

### 💼 3. Career Opportunities
- Explore career opportunities.
- Discover potential job options.
- Support career planning and development.

### 📄 4. Create Resume
- Create professional resumes.
- Organize educational qualifications.
- Present skills and personal details professionally.

### 👤 5. Profile
- Access personal profile information.
- Manage user details.
- Maintain personal career information.

## ⚙️ Installation and Setup

### 1. Clone Repository

```bash
git clone https://github.com/Sankari-Pradhan/SkillBridge.git
```

### 2. Navigate to Project

```bash
cd SkillBridge
```

### 3. Create Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Environment

Windows:

```bash
venv\Scripts\activate
```

Linux / Ubuntu:

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

Use the appropriate backend module path:

```bash
uvicorn main:app --reload
```
